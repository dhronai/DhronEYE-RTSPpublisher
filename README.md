# DhronEYE RTSP Publisher

Desktop app that publishes your cameras to the DhronEYE stream server, with on-device object detection, so a single stream link shows live video and detections in [dhronEYE](https://dhroneye.dhronai.com).

## Download

Get the installer for your platform from the [latest release](https://github.com/dhronai/DhronEYE-RTSPpublisher/releases/latest):

| Platform | File |
|---|---|
| Windows 10/11 (x64) | `DhronaIntel-<version>-Windows-AMD64.exe` |
| macOS (Apple silicon) | `DhronaIntel-<version>-Darwin-arm64.dmg` |
| Linux (x86-64, Debian/Ubuntu) | `DhronaIntel-<version>-Linux-x86_64.deb` |

This repository hosts releases only. Source code is maintained privately by DhronAI.
